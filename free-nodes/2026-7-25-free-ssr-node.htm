一、什么是 Quantumult X？

Quantumult X 是一款在 iOS 上运行的综合性网络代理工具，集成了 Shadowsocks、VMess、Trojan 等主流协议，并支持订阅配置、策略路由、规则分流、自定义 DNS 解析、重写脚本等高级功能。

相比其他 VPN 或翻墙类 App，Quantumult X 更加专业、可控，几乎可以满足所有对“科学上网”有更高需求的用户。

核心功能一览：

  • 多协议支持（SS、V2Ray、Trojan 等）

  • 自定义代理规则与策略组

  • 精细化流量管理与统计

  • 强大的 URL Rewrite 与 Header 重写功能

  • 高度兼容 Surge、Clash 格式的订阅链接

二、Quantumult X 的下载方式

Quantumult X 并非免费工具，也不提供试用，但其在 App Store 上是正规上架应用，下载过程相对简单。

1. 通过 App Store 下载

这是最直接、安全的方式：

  • 打开 iPhone 或 iPad 的 App Store

  • 在搜索栏输入 “Quantumult X”

  • 找到正版应用，图标呈现黑底 X 字样，价格一般在 5.99 - 7.99 美元区间（根据地区浮动）

  • 点击“购买”并输入 Apple ID 密码或使用面容识别购买

  • 等待下载并自动安装完成

**温馨提醒：**Quantumult X 是一次性买断制，购买后可永久使用，无年费/月费压力。

2. 注意事项

  • 需使用支持购买的 Apple ID 账户（如港区、美区、日区等）；

  • 中国大陆 App Store 通常搜索不到该软件，建议切换账号；

  • 切勿下载破解版本或非官方渠道 IPA 文件，以免安全受损或账户被封。

三、安装 Quantumult X 后的初步操作

第一步：初次打开应用

  • 安装完成后，点击 App 图标启动 Quantumult X；

  • 同意应用权限请求，包括 VPN 配置许可、通知权限等；

  • 若首次进入需要“导入配置”，可先跳过，后续再设置。

第二步：准备订阅链接

Quantumult X 并不会默认提供代理节点服务，你需要从第三方服务商处购买代理服务，然后获取包含你所有节点信息的订阅链接。

四、添加订阅链接与配置节点

如何导入订阅？

  1. 进入 Quantumult X 主界面；

  2. 点击右下角 “设置” 图标 → 进入“配置文件”；

  3. 点击“订阅管理”；

  4. 添加新订阅 → 粘贴你复制的链接 → 命名（如：MyVPN）；

  5. 点击“完成”并手动刷新订阅。

节点选择与分组策略设置

  1. 进入“策略”界面；

  2. 可见已同步的节点列表，点击任意节点可测速；

  3. 设置“策略组”进行自动选择最佳节点；

  4. 常见策略分组方式：自动切换、故障转移、负载均衡等。

五、网络规则与分流策略配置

Quantumult X 的核心魅力之一就是规则分流，你可以自由决定哪些网站走代理，哪些不走，提高访问效率并节省流量。

常见的规则模式：

  • 全局模式：所有流量走代理（适合初学者）

  • 规则模式：按规则分流（推荐）

  • 直连模式：所有网站都不代理

如何设置规则：

  1. 进入“设置” → “规则”

  2. 可导入 Surge 或 Clash 的规则文件（需转换为 Quantumult X 格式）

  3. 支持域名关键字、自定义 URL、GEOIP 区域识别等方式

  4. 建议使用第三方维护的规则文件，如 lhie1、ACL4SSR 等，便于更新

六、流量监控与高级功能

FAQ

Mellow TUN 模式的全局代理作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 可覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定顺畅。
Mellow TUN 模式对系统全局流量的作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 能覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定高效。
Nekobox 可以自定义路由规则吗？
支持。用户可通过界面或配置文件定义路由规则，按域名、IP 或端口匹配不同节点，实现流量分流。自定义规则增强了网络访问灵活性和安全性。
Clash 的配置文件是 YAML 格式吗？
是的。Clash 的配置文件采用 YAML 格式，结构清晰易读。用户可以通过编辑 proxies、proxy-groups 和 rules 部分来自定义节点列表、分组策略和分流规则，非常灵活。
Mellow 支持哪些平台？
Mellow 是基于 Electron 的跨平台代理工具，支持 Windows、macOS 和 Linux。它通过 TUN 模式接管全局流量，并支持 Clash 规则和订阅格式，非常灵活。
V2Ray 的策略组如何根据延迟自动选择节点？
策略组可通过节点延迟测试结果自动选择最优节点。结合路由规则，可保证国内流量直连、海外流量走最佳节点，提高访问速度和连接稳定性，优化整体网络体验。
VLESS 的 XTLS 模式能提升传输效率吗？
XTLS 模式通过减少冗余加密和握手次数，降低延迟，提高吞吐量。在高并发和短连接场景下，效率明显优于普通 TLS，同时保持数据安全性和隐蔽性。
Matsuri 节点延迟排序功能如何使用？
Matsuri 会定期测速节点延迟，并结合策略组自动选择延迟最低节点。用户无需手动切换即可保持高速访问，优化网页、视频和游戏体验，提高网络稳定性。
如何配置 Clash 以支持局域网内设备共享代理？
启用 Clash 的 HTTP/SOCKS5 本地监听并在局域网设备上设置该代理地址为网关；若使用 TUN 模式需配合路由器或透明代理实现全局共享，注意开启访问控制避免未经授权的外部访问。
Sing-box 精确端口分流如何提升游戏体验？
Sing-box 可按端口设置流量分流规则，将游戏流量分配到低延迟节点。结合策略组使用，可保证游戏连接稳定，减少延迟和掉线，提高流畅度。
